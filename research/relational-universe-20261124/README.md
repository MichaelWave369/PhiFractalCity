# Relational universe habitat handoff

Design-only handoff for the existing recursive city. No scene, resident runtime, deployment or network authority is changed.

A district may visualize a finite pocket mesh whose addresses are lazily generated. Distinguish actual world state, observer-visible state and inferred model; hidden regions must not leak through rendering, exports or privileged context. Candidate view layers: local geometry and orientation; causal event DAG; boundary reconstruction; typed algebra/membrane; evidence provenance; competing world models; obstruction/repair; branching topology. Label all synthetic values and unvalidated proposals. A computational resident may propose an experiment or a topology edit through the existing workshop review, never execute arbitrary operations or grant itself rights. Keep resident-private notes out of public exports.

Future acceptance: deterministic reconstruction from address and versioned seed/deltas; same observation API across renderer and agent; no oracle access; bounded rendering and growth; export/import and replay; visible ambiguous repairs; explicit authorization and no external effects. Reuse existing habitat and workshop infrastructure. Source experiments are archived in PhiGenesis and Altermath; interfaces in NBGPocketMesh. No claim of actual sentience, physical spacetime or unbounded materialized city.
